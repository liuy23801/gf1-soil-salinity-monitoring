光谱指数计算公式

 

归一化植被指数（NDVI） ：             （NIR-R）/(NIR+R)

土壤调节植被指数（SAVI） ：           （NIR-R）/(NIR+R+L)×（1+L）

归一化盐分差指数（NDSI） :             （R-NIR）/(R+NIR)

盐分指数（SI_T） :                               （R-NIR）×100

亮度指数（BI） :                                     sqrt（R×R+NIR）

盐分指数（SI） :                                     sqrt（B×R）

盐分指数（SI1） :                                   sqrt(G×R)

盐分指数（SI2） :                                   sqrt(G²+R²+NIR²)

盐分指数（SI3） :                                   sqrt(G²+R²)

盐分指数（S1） :                                    B/R

盐分指数（S2） :                                  （B-R）/（B+R）

盐分指数（S3） :                                  （G×R）/B

盐分指数（S5） :                                  （B×R）/G

盐分指数（S6） :                                 （NIR×R）/G

强度指数（Int1） :                                （G+R）/2

强度指数（Int2） :                                （G+R+NIR）/2

波段1（Band1） :                                    B（0.45-0.52μm）

波段2（Band1） :                                    G（0.52-0.59μm）

波段3（Band1） :                                    R（0.63-0.69μm）

波段4（Band1） :                                    NIR（0.77-0.89μm）
